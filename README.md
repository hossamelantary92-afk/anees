# حصن الأذكار — v2.1 إصلاح الصفحة البيضاء

## الفتح المباشر
فك ضغط الملف ثم افتح index.html في المجلد الرئيسي. الكود والتنسيق مضمنان فيه؛ لا يحتاج npm للاستخدام المباشر. عند غياب الإنترنت قد يظهر خط النظام.

## النشر على Vercel
Build command: npm run build
Output directory: dist
أُرفق vercel.json لضبطهما. ويمكن رفع index.html وحده لاستضافة ثابتة.

## التطوير
npm ci ثم npm run dev، وافتح /app.html.
مصدر Vite هو app.html؛ ملف index.html يُولّد تلقائيًا بواسطة npm run build.
أدوات التطوير تتطلب Node.js 22.12 أو أحدث.

## الإصلاحات
تضمين JavaScript وCSS في HTML، ومسارات نسبية، وحماية التخزين المحلي والتحقق من بياناته، وشاشة خطأ قابلة للاسترداد. إلغاء تسجيل عامل التخزين السابق عند فتح النسخة الجديدة من نفس مساره، دون حذف بيانات القراءة.

## المزايا المحفوظة
70 بطاقة، النصوص الكاملة للسور، قراءة مركزة وقائمة، مفضلة، بحث بدون تشكيل، تراجع، أصوات هادئة، وتقدم مستقل لكل صلاة.

## المحتوى
توسعة منتقاة وليست حصن المسلم كاملًا، ولا تمثل تحقيقًا شرعيًا مستقلًا لكل تخريجات الملف الأصلي. مراجع داخل البطاقات، مع الرجوع إلى https://hisnmuslim.com/ و https://dorar.net/hadith .

## التحقق
نجاح بناء الإنتاج وفحص TypeScript، وفحص وجود الكود والتنسيق داخل HTML، وظهور النسخة المستقلة في المتصفح وتبديل أقسامها. لم يُختبر جهاز المستخدم أو سياق الاستضافة الفعلي.

## تحديث v2.2 للجوال

البداية الافتراضية دائمًا أذكار الصباح، المفضلة قسم مستقل في التنقل، المصادر في الإعدادات، وإضافة ست بطاقات بمراجعها ليصبح الإجمالي 76. تم التحقق من العودة للصباح بعد تحديث الصفحة من قسم المساء، ومن ظهور العناصر المحفوظة في قسم المفضلة.

## تحديث v2.4 — عباداتي
- تنقل رئيسي: الأذكار، عباداتي، المفضلة، السبحة. البداية تظل أذكار الصباح.
- تسجيل الصلاة والنوافل وأعمال الخير، مع التراجع بضغطة ثانية.
- قراءة القرآن بأهداف حسب الصفحات أو الدقائق أو الحزب أو الجزء؛ الحفظ والمراجعة اختياريان بالآيات، وعلامة قراءة مشتركة.
- تبويبا اليوم والسجل، تقويم شهري وتعديل الأيام السابقة. بدون تسجيل لا تعني عدم أداء العبادة.
- تقدم أذكار الصباح والمساء تلقائيًا، وأرشفة من تاريخ استخدام النسخة. لا يُنشأ تقدم وهمي للأيام السابقة.
- «خطتي» لإخفاء وإظهار الأقسام وتغيير الأهداف والنوافل وإضافة عادات خاصة.
- تصدير واستعادة JSON من «خطتي»؛ الاستعادة تعرض تأكيدًا قبل استبدال بيانات المتصفح.
- النسخة الاحتياطية تشمل سجل عباداتي والخطة وعلامة القراءة وتقدم الأذكار اليومي وتاريخه؛ المفضلة وإعدادات المظهر لا تدخل فيها.
- الحفظ في المتصفح فقط، دون حساب أو مزامنة سحابية. احتفظ بنسخة احتياطية قبل تغيير الجهاز أو مسح بيانات المتصفح.
- مراجعة الجوال بعرض 390 بكسل، واختبار حفظ الصلاة والقرآن والصدقة بعد إعادة الفتح، وتقويم الأيام غير المسجلة، والانتقال لورد المساء وتحديثه في عباداتي.
- اختبارات بيانات: npm test، وفحص TypeScript وبناء الإنتاج.

## تحديث v2.5 — موضع القراءة
قائمتان للسورة وآخر آية مقروءة، مع حدود الآيات الخاصة بكل سورة واقتراح موضع الاستكمال. الموضع القديم النصي محفوظ حتى تسجيل اختيار جديد، والنسخ الاحتياطية السابقة متوافقة. بيانات أسماء السور وعدد الآيات مضمنة محليًا من Quran.com API: https://api.quran.com/api/v4/chapters?language=ar . لا يحتاج اختيار السورة للإنترنت.

## تحديث v2.6 — الخطة وقائمة الإتمام
- القراءة والحفظ والمراجعة بعلامات إتمام بدل العدادات، مع تراجع عن آخر إجراء.
- مقاطع حفظ ومراجعة بالسورة ونطاق الآيات، تعديل وحذف بتأكيد، وتنبيه عند التداخل.
- مراجعات متكررة حسب أيام الأسبوع أو يوميًا؛ دعم عدة جولات لنفس المقطع، وحساب الآيات المختلفة دون مضاعفة المتداخل.
- زر الاستكمال من الآية التالية للمقطع السابق، مع مراجعة الاختيار قبل الحفظ.
- الخطة تتكرر بعلامات فارغة في الأيام الجديدة؛ يبقى مقطع الحفظ حتى تعديله.
- يحتفظ كل يوم بنسخة من أهدافه ومقاطعه، وتعديل الخطة يؤثر على اليوم والمستقبل فقط. يمكن تعديل هدف يوم واحد من داخله.
- الصيام اختياري من «خطتي»، بنية مستقلة عن إتمام اليوم ونوع رمضان/قضاء/تطوع.
- ترتيب وإخفاء الأقسام والعادات الخاصة قابل للتغيير مع الاحتفاظ بالسجل.
- ملخص 7 أيام داخل «السجل»، يفرق بين أيام بدون تسجيل وأيام مسجلة، دون درجة إجمالية للعبادات.
- المقادير العددية القديمة محفوظة وتظهر كتسجيلات سابقة؛ لا يتم تحويلها تلقائيًا إلى علامة إتمام. أهداف الأيام القديمة قبل هذا التحديث لم تكن محفوظة؛ تُلتقط نسخة من الخطة الحالية عند الترقية، ثم تبقى مستقلة من وقت التحديث.
- إعدادات إظهار الحفظ والمراجعة السابقة محفوظة. إذا كان القسم مخفيًا فعّله من «خطتي»، أو أضف له مقطعًا من الخطة.
- يظل التطبيق يفتح على أذكار الصباح، وعلامة آخر موضع قراءة مستقلة عن إتمام الورد.
- نجاح الاختبارات للخطط المتكررة وحماية السجل وجدولة المراجعة وحساب التداخل وتوافق النسخ الاحتياطية، مع اختبارات متصفح للحفظ والإتمام والتراجع والصيام وعرض الجوال 390px.

## تحديث v2.7 — القوائم والجمعة والقرّاء
- أيام تكرار المراجعة تبدأ بالسبت حتى الجمعة مع الحفاظ على ربط كل يوم الصحيح بالتسجيلات السابقة.
- ألوان خلفية ونص واضحة لعناصر select وoption في الوضعين، مع color-scheme مطابق للوضع المختار.
- قائمة آيات آخر موضع قراءة متاحة من البداية، وتبدأ السورة بالفاتحة إذا لم توجد علامة محفوظة، مع تحديث خيارات الآيات عند تغيير السورة.
- رمضان أول اختيار للصيام والافتراضي للتسجيل الجديد؛ حُذفت خانة النية من الواجهة، والتسجيلات السابقة بأنواعها محفوظة.
- ورد الجمعة للصلاة على النبي يظهر في عباداتي يوم الجمعة، وكذلك عند اختيار يوم جمعة في السجل؛ يمكن إخفاؤه من خطتي. علامة الإتمام شخصية دون عدد مفروض.
- المفضلة بها تبويبان: الأذكار المفضلة، وقرّاء القرآن. يمكن إضافة اسم القارئ وتعديله وحذفه، مع رابط تلاوات اختياري يفتح خارجيًا؛ لا يوجد بث صوتي داخلي ضمن هذه الميزة.
- القرّاء محفوظون على المتصفح في hisn_reciters، وخارج نسخة عباداتي الاحتياطية مثل بقية المفضلة.
- نجاح اختبار إضافة وتعديل قارئ وبقائه بعد إعادة الفتح، وتفعيل قائمة الآيات، وتباين ألوان الخيارات، وظهور ورد الجمعة، واختبارات ترتيب الأيام وتوافق البيانات السابقة.
