# حصن الأذكار اليومية — الإصدار الثاني

## التشغيل
- Node.js 22.12 أو أحدث.
- `npm ci`
- `npm run dev`
- للإنتاج: `npm run build`، ومجلد النشر `dist`.
- على Vercel: Framework = Vite، Build = npm run build، Output = dist.

## الجديد
- 70 بطاقة موزعة على 7 أقسام، مع نص السور الثلاث كاملًا.
- وضع قراءة ذكر واحد أو عرض القائمة، وحفظ موضع الذكر.
- انتقال تلقائي اختياري، مفضلة، بحث يتجاهل التشكيل، وتراجع عن العد.
- أصوات هادئة منخفضة الشدة بدل النقر الحاد ولحن الإكمال السابق.
- فصل أعداد التسبيح والتحميد والتكبير.
- تقدم مستقل لكل صلاة، ودعاء العلم النافع يظهر بعد الفجر فقط.
- إعادة يومية حسب تاريخ الجهاز المحلي، مع اكتشاف تغيّر اليوم عند العودة للتطبيق.
- عد النص لم يعد يتغير عند لمسه، بل من زر العد فقط.
- تجهيز PWA والتخزين المحلي للعمل دون اتصال بعد أول فتح ناجح للنسخة الإنتاجية على HTTPS. الخطوط الخارجية قد تستخدم بديلًا محليًا دون اتصال.

## المحتوى والمراجع
- توسعة منتقاة وليست نسخة كاملة من كتاب حصن المسلم.
- المرجع العام: https://hisnmuslim.com/ ، مع إحالات الكتب والأحاديث داخل كل بطاقة وروابط للرجوع إليها.
- المراجعة الحديثية: https://dorar.net/hadith
- لا يُنسب عدد شرعي للذكر المطلق من مجرد عدّاد الواجهة؛ بعض الأدعية المطلقة لها زر إكمال قراءة فقط.
- لا تمثل النسخة مراجعة شرعية مستقلة لكل تخريجات الملف الأصلي؛ يُستحسن مراجعة مختص قبل النشر العام بوصفه مرجعًا محققًا.

## التحقق
تم نجاح بناء الإنتاج وفحص TypeScript، وتجربة القراءة والعد والتراجع وحفظ المفضلة بعد التحديث واستقلال جلسات الصلاة في المتصفح. لم يتم اختبار التثبيت والعمل دون اتصال على جهاز جوال فعلي أو تقييم الصوت بالاستماع على أجهزة مختلفة.
